# مرحله ۳.۴ ـ OCR فارسی صفحات اسکن‌شده

## هدف و محدوده
این مرحله OCR را فقط برای صفحات منتخب PDFهای دریافت‌شده اجرا می‌کند. اگر `page_numbers` داده نشود، صفحات کم‌متن با استفاده از طبقه‌بند مرحله ۳.۳ انتخاب می‌شوند. انتخاب دستی صفحات نیز ممکن است.

## رفتار ایمنی
- زبان پیش‌فرض `fas+eng` است و وجود زبان‌ها در Tesseract پیش از اجرا بررسی می‌شود.
- OCR اختیاری است؛ نبود Tesseract یا داده زبان فارسی با خطای روشن متوقف می‌شود.
- DPI، تعداد صفحات، زمان هر صفحه و تعداد پیکسل تصویر محدود هستند.
- متن OCR در sidecar مستقل JSON ذخیره می‌شود؛ PDF اصلی و بانک فعال JSON تغییر نمی‌کنند.
- برای هر صفحه شماره، متن، تعداد واژه، میانگین confidence، زبان، وضعیت و هشدار ثبت می‌شود.
- خروجی همیشه `review_required=true` و provenance برابر `tesseract_ocr_machine_generated` دارد. خروجی OCR نباید بدون بازبینی انسانی به‌عنوان متن معتبر قانون استفاده شود.
- OCR خودکار برای صفحات دارای متن کافی انجام نمی‌شود، مگر آنکه شماره صفحه صریحاً انتخاب شود.

## پیش‌نیاز
نصب Tesseract OCR و داده زبان‌های `fas` و `eng`، به‌علاوه بسته‌های Python پروژه (`PyMuPDF`, `pytesseract`, `Pillow`). این ماژول در نبود پیش‌نیازها fail-closed عمل می‌کند.

## نمونه استفاده
```python
from legal_bot.ingestion.persian_pdf_ocr import ocr_pdf_pages, write_ocr_json

result = ocr_pdf_pages("staging/sha256.pdf")  # صفحات کم‌متن مرحله ۳.۳
write_ocr_json(result, "staging/ocr/sha256.ocr.json")
```

## محدودیت‌ها
- کیفیت OCR به وضوح اسکن، فونت، چرخش، جدول‌ها و کیفیت داده زبان فارسی بستگی دارد.
- confidence تسرکت معیار قطعی صحت حقوقی نیست.
- این مرحله تشخیص و اصلاح خودکار اشتباهات حقوقی، بازسازی جدول‌ها یا ورود به بانک قوانین را انجام نمی‌دهد.
- آزمون‌های خودکار با خروجی OCR کنترل‌شده (mock) انجام می‌شوند؛ دقت واقعی روی اسناد رسمی باید در مرحله ارزیابی نمونه‌های واقعی اندازه‌گیری شود.
